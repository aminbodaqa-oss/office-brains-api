# Vindora Office — Android Native

تطبيق Android أصلي مبني بـ React Native + Expo، وليس WebView. يتصل مباشرةً بخدمة Office Brains API الحالية وقاعدة بياناتها، ولا ينشئ قاعدة بيانات منفصلة.

## التشغيل محليًا
```bash
cd mobile
npm install
npx expo start
```

لإنشاء APK تجريبي باستخدام EAS:
```bash
npm install -g eas-cli
eas build:configure
eas build --platform android --profile preview
```

## إعدادات مهمة
- API الافتراضي مضبوط على خدمة المكتب الحالية في `src/api.ts`.
- رمز الدخول يُحفظ في Android SecureStore.
- لا تضع مفاتيح Gemini أو أسرار Backend داخل التطبيق.
- أي تغيير في قاعدة البيانات أو API يجب أن يظل متوافقًا مع تطبيق الويب الحالي.

## حالة المرحلة الأولى
هذه بداية التطبيق الأصلي: تسجيل الدخول، الرئيسية، الموظفون والمحادثات، المهام، الاجتماعات، الإشعارات، وتقارير التشغيل. يجب استكمال مطابقة كل تفاصيل الواجهة الحالية واختبارها قبل اعتبار التطبيق جاهزًا للإنتاج. إشعارات Push وقت إغلاق التطبيق تتطلب إعداد خدمة Push وربط Backend، وهي ليست مفعّلة في هذه المرحلة.
