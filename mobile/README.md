# Vindora Office — Android Native

تطبيق Android أصلي مبني بـ React Native + Expo، وليس WebView. يتصل مباشرةً بخدمة Office Brains API الحالية وقاعدة بياناتها، ولا ينشئ قاعدة بيانات منفصلة.

## التشغيل محليًا
```bash
cd mobile
npm install
npx expo start
```

لإنشاء APK تجريبي باستخدام EAS:
```bash
npm install -g eas-cli
eas build:configure
eas build --platform android --profile preview
```

## إعدادات مهمة
- API الافتراضي مضبوط على خدمة المكتب الحالية في `src/api.ts`.
- رمز الدخول يُحفظ في Android SecureStore.
- لا تضع مفاتيح Gemini أو أسرار Backend داخل التطبيق.
- أي تغيير في قاعدة البيانات أو API يجب أن يظل متوافقًا مع تطبيق الويب الحالي.

## حالة التنفيذ الحالية
التطبيق يحتوي على تسجيل الدخول، الرئيسية، الموظفين الـ13 ومحادثاتهم، المهام، الاجتماعات، الإشعارات داخل التطبيق، التقارير اليومية، سجل النشاط، ذاكرة الموظفين، ملخص سلمى، وتغيير كلمة المرور.
غرفة الاجتماعات تحفظ نص الجلسة ومحضر سلمى وحالة الاجتماع عبر `PATCH /api/meetings/{id}`. يجب نشر تحديثات `backend/` من هذا الفرع على خدمة الـAPI قبل اختبار هذه الوظيفة على الهاتف.
إشعارات Push عند إغلاق التطبيق لم تُفعّل بعد؛ تحتاج ربط Expo Push مع مشروع EAS وتخزين رموز الأجهزة وإرسالها من الـBackend.
لم يتم إصدار APK بعد. يجب نجاح فحص TypeScript وبناء Android ثم اختبار الاتصال الفعلي قبل اعتبار التطبيق جاهزًا.
