# Office Brains

الواجهة الأمامية لمنصة Office Brains، وتشمل الموقع التعريفي العام، مساحة العمل، ومركز السوبر أدمن.

يتم نشر محتويات هذا المجلد عبر GitHub Pages. نقطة اتصال الواجهة بالـBackend موجودة في `frontend/js/config.js` داخل المتغير `OFFICE_API_URL`.

لا تضع مفاتيح API أو أسرارًا في ملفات الواجهة العامة.
